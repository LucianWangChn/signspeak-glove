# 视频版闭环演示目录说明

这个目录用于结课视频拍摄，目标是把系统收束成稳定可拍的闭环：

```text
手语短句识别 → 电脑播报
母亲语音/剧情触发 → BLE 手套反馈 → OLED 中文状态显示
```

## 子目录

```text
手语短句识别/
OLED中文反馈/
拍摄控制台/
```

## 1. 手语短句识别

视频专用短句分类，不做开放词表翻译。

标签：

- 1 = 住院交费
- 2 = 不用担心陪你
- 3 = 去办手续
- 0 = 静止

实际脚本仍放在主项目：

```text
<LOCAL_PROJECT_PATH>
<LOCAL_PROJECT_PATH>
<LOCAL_PROJECT_PATH>
```

## 2. OLED 中文反馈

不推荐完整中文字库。推荐固定中文点阵：Python/BLE 只发状态码，Arduino 本地画中文字形。

状态码：

- TW = 担忧
- TS = 焦虑
- TA = 安心
- TR = 放松
- TC = 平静
- TO = 接受

## 3. 拍摄控制台

`shooting_controller.py` 用于场外同学按键触发手套反馈。它会同时发送：

1. 兼容 PRD 区域码，如 NL/PL/NT
2. 中文点阵状态码，如 TW/TA/TC
3. 旧版 OLED 文本兜底，如 T:TW

这样无论 Arduino 当前支持哪一层协议，都尽量能有反馈。
